# Vincula 0.4.4 — Local Audit UI v2（D53-rev1 / §16）

**Stamp:** CTRL `0.4.4` · NODE `0.3.1`（不变）  
**Authority:** this file + [`vcl-spec-v0.4-v0.5-rev1.md`](vcl-spec-v0.4-v0.5-rev1.md) §16.

## Goal

Full Local Audit UI v2 per rev1 §16: six pages, Overview KPIs / trends, Nodes / Users / Traffic / Audit enrichment, Operations history, and **Command Builder** (no identity mutations).

| In | Out |
| --- | --- |
| Overview: health, counts, traffic today, last sync, cache age, trend, top users/hosts, recent problems | UI identity mutations |
| Nodes: users / traffic today / endpoint; detail users + last operations | Rendering VLESS URI / credential UUID / Reality key / Clash secret |
| Users: department, enabled state, today / 30D | Running provision/adopt/rotate from UI |
| Traffic: node/user/department/destination filters, trend, upload/download | Probe rewriting last-status.json |
| Audit: destination IP / port / network filters (SQL before LIMIT) | |
| Command Builder: fill fields → complete CLI (D53 No → Builder only) | |
| Probe live overlay; Sync = `sync --full` | |

## Non-negotiables (inherit AC-3.1)

1. Loopback-only bind.
2. `identity_mutations: false`; mutate POST → **405**.
3. `reseed` CLI-only.
4. No secrets / credential UUID in default JSON / pages (`has_active_credential` only).
5. Closing UI does not affect VPS nodes.
6. Probe does not write `last-status.json`.
7. Workspace GET never mkdir / migrate view.
