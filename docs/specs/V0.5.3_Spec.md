## M1：冻结的 Node Inspect 合同

固定命令 `vcl inspect --json`，capability 为 `inspect/v1`，observer 只接受这两个参数。安装、runtime-only、升级 checkpoint/rollback、卸载与 Node/Controller 制品清单均包含 collector。Controller 此阶段仅提供身份绑定的内部 observe fetch；尚无 Controller inspect CLI、缓存、Drift 或新 Verify。

[正式 schema](../../schemas/inspect/v1.schema.json)与 `lib/inspect_snapshot.py` 的 `contract()` 必须相等，正反 fixture 同时经过正式 schema 和完整 runtime validator。所有字段固定、禁止附加字段；root 含 schema、node_id、instance_id、observed_at、state。root OK 必须身份完整且全部分项 OK；身份未知为 UNKNOWN，其余不完整为 PARTIAL。node_id 与 instance_id 不相同。

每分项固定 `state=OK/PARTIAL/UNKNOWN/UNSUPPORTED/UNREADABLE`、`reason=NONE/MISSING/MISSING_TOOL/PERMISSION/INVALID/LIMIT/TIMEOUT/COMMAND_FAILED/SYMLINK/UNSUPPORTED_OS`。OK 必须 reason NONE；不可读、缺工具、超时和不完整不变成健康零。数组截断必须 PARTIAL/truncated=true。

| 分项 | 冻结字段与含义 |
| --- | --- |
| OS / CPU / memory | ID、VERSION_ID、kernel、supported；CPU 数；RAM 与 swap total/available 字节。支持矩阵 Debian 12/13、Ubuntu 22.04/24.04/26.04；其他 OS 明确 UNSUPPORTED。available 大于 total 拒绝 |
| filesystems | 固定 `/`、`/var`、`/run`、`/tmp` 的 capacity/available 字节与 filesystem；只代表这四个路径，未知 mount type 为 PARTIAL |
| clock | NTPSynchronized、NTP、Timezone 的只读 property；同步未知不当 true |
| interfaces / qdisc | 网卡 name/MTU/admin-up/loopback；qdisc interface/kind/root。接口枚举最多读取65项、保留64项；不宣称包含全部网卡 |
| selected sysctl | TCP congestion control、default_qdisc、IPv4/IPv6 forwarding、tcp_mtu_probing、somaxconn；固定 proc 文件，无写入 |
| limits / services | system file-max、当前 observer 进程 nofile soft/hard（不是 sing-box limits）；sing-box/accountd 固定 unit 的 active/enabled/restart count/User/Group/nofile soft/hard |
| versions | CLI VCL、installed VERSION；sing-box 版本仅在安装 lock 记录的 binary SHA 与实际字节一致时为 INSTALLED_MANIFEST，否则 UNKNOWN；禁止执行受检 binary |
| listeners | TCP/UDP、IPV4/IPV6/ANY、LOOPBACK/LINK_LOCAL/NON_LOOPBACK、规范地址、zone interface、port。固定 ss 无 process/argv；非 loopback 并不等于公网实际可达 |
| firewall | nft family/hook/base policy、chain-name hash 与 rule count；不返回完整规则或 comment。仅缺 nft 时尝试两个 iptables-save family；缺一个 family 为 PARTIAL；base policy 不证明真实放行 |
| updates | 只读 update-notifier 缓存 counts 与 reboot-required marker-present；缺缓存为 UNKNOWN，marker 缺失仅表示该标记不存在，不证明无需重启 |
| fingerprints | managed-config/v1 non-secret canonical SHA、binary SHA、4个 unit 和10个固定 runtime artifact 的 SHA/mode/uid/gid；每项独立状态，不回传 raw config、路径或错误文本 |

## 只读、秘密与资源边界

collector 默认共享6秒预算，内部最多8秒；每个固定外部 argv 最多1秒、stdout≤64KiB、stderr丢弃。Linux 使用有界 pipe drain，超时/超量 kill 整个 process group，包括父进程先退出的子进程；无 shell。固定 sys/proc/小文件≤1MiB，config≤4MiB，binary streaming hash≤256MiB；输出 compact JSON≤64KiB；公开数组≤64项。非 regular 文件拒绝，配置/lock/指纹文件拒绝 symlink，检查读取期间及路径标识变化。无需执行受检 binary、package refresh/update、restart、sysctl 写入或 reconcile。

observer unit允许AF_NETLINK供只读ss/tc读取，CapabilityBoundingSet仍仅CAP_DAC_READ_SEARCH，不增加CAP_NET_ADMIN。防火墙工具可能因权限受限失败，保留UNKNOWN/COMMAND_FAILED；没有现场证明完整firewall覆盖。systemd隔离与实际工具权限在PENDING LIVE中核对。

config 仅识别当前受管 renderer 的严格字段集合，拒绝 duplicate key、non-finite、未知 shape/字段、非法类型。VLESS credential UUID、Reality private/short keys、Clash secret 在 canonical hash 前删除；secret rotation 不改变 non-secret fingerprint。用户/tag、listener、route/outbound 顺序等有效非秘密行为改变会改变 hash。响应含逻辑 node/instance UUID，不含用户 credential UUID。模式或权限未知不冒充安全。

Controller fetch 固定 `vcl inspect --json` 后读取 `vcl identity --json`，校验 registry node_id 与当前 instance_id；仅 observe 凭据，无 admin fallback，capability 缺失不 SSH。调用方必须提供一次覆盖 capability/inspect/identity 的总 deadline。新 fetch 尚未接入 monitor，这项集成与 deadline 证明在 M2 完成。

property 依据：[systemctl show](https://github.com/systemd/systemd/blob/main/man/systemctl.xml)、[timedate1 property](https://github.com/systemd/systemd/blob/main/man/org.freedesktop.timedate1.xml)、[service exec limits](https://github.com/systemd/systemd/blob/main/man/systemd.exec.xml)。读取单位含义以分项定义为准，原始工具输出不会回传。
