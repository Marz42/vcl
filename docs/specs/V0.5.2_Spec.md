## Finding / Evaluation 合同

`findings/v1` 包含 `cache_state`、`findings`、`evaluations`、`events`、`truncated`。状态为 `EMPTY / OK / PARTIAL / CACHE_CORRUPT`。每个 Finding 有：

正式JSON合同：[findings/v1](../../schemas/findings/v1.schema.json)、[timeline/v1](../../schemas/timeline/v1.schema.json)。全部公开schema随Controller ZIP分发且纳入controller.lock。14个正反fixture和真实缓存输出验证Node/User类型关联、固定分类/解释、白名单和有界数组；hash/父级关联/时间顺序由runtime另验证。

| 字段 | 语义 |
| --- | --- |
| finding_id | SHA-256(subject key, type)，同类型同逻辑节点稳定去重 |
| type / category / severity | 固定类型及 `WARNING / ERROR`，不用远端自由文本 |
| subject | `kind=node`、当前 registry 名称、逻辑 node_id 的不透明 hash；不复制 endpoint/credential |
| state | `ACTIVE / RESOLVED`；ACKNOWLEDGED/SUPPRESSED 留给后续阶段 |
| first_seen / last_seen | Controller Unix 秒；first_seen 跨重开保持，last_seen 为最近确定异常或确定恢复的评估时间 |
| evidence / explanation | 有界数值/布尔白名单与固定解释；不复制原始 JSON、argv、URI、凭据 UUID 或异常文本 |

每节点/用户保存最近 `evaluated_at` 和各检测的 `ANOMALOUS / NORMAL / UNKNOWN`。这些是历史评估，显示时应查看评估时间；读取不刷新评估。UNKNOWN 不创建正常值，也不关闭已有 ACTIVE。相同/倒退评估时间不覆盖新状态。节点/用户tag改名不改变去重键；不同逻辑 identity 不共用 Finding。M3 用户subject为kind=user，name为当前node名，附node/user hash和白名单user_tag；不回显逻辑/credential UUID。

## M1 检测规则

| Type | 触发 / 恢复 | UNKNOWN 边界 |
| --- | --- | --- |
| AUDIT_STALLED | accountd inactive，或成功 poll age >90s；active 且 poll age ≤90s 恢复。缓存重分析会加上 snapshot 已过去的时间 | telemetry 非新鲜、缺 poll age 且 active、无观察 |
| EXPORT_GAP | 同 instance、`export_seq` cursor 的持久 status=expired；status=ok 恢复 | 缺 cursor、不同 instance、event_id cursor、error。export_seq 跳号合法，不单独视为丢失 |
| SYNC_LAG | 同 instance 的成功 cursor 落后远端 export_seq，且同步时间过去 >300s；追平或成功同步年龄 ≤300s 恢复 | 无 cursor/时间、cursor ahead、失败同步时间、旧协议、实例变更 |
| DISK_PRESSURE | `/` 使用率 ≥90%；ACTIVE 时低于 85% 恢复 | 缺值、total=0、used>total、非新鲜 telemetry |
| MEMORY_PRESSURE | 内存使用率 ≥90%；ACTIVE 时低于 85% 恢复 | 同上 |
| TELEMETRY_STALE | observed_at 年龄 >90s，领先 >30s，或既有 health 标记回放/乱序 | 无 observed_at；新鲜且无回放标记恢复 |

M1 压力检测是单次确定阈值 + hysteresis；统计基线、连续时长和误报矩阵尚未实现。stationary export_seq、last event age 很大不能单独证明 accountd 停滞，空闲节点不会因此产生 stall。

## M2 独立审计诊断与推进

Node capability 增加 `audit-health/v1`，固定命令 `vcl telemetry audit --json`；schema 与正反例分别在 `schemas/audit-health/`、`tests/fixtures/schemas/audit-health/`。旧 telemetry/v1 保持原形状。Controller 按 capability 选择该固定 observe 命令，共用单节点总 SSH deadline；诊断失败保留已取得的 telemetry，不回退 admin。受限 observer 仅增加此固定只读命令。

Node 输出逻辑 node/instance identity、UTC observed_at、accountd_active、db_state 和 nullable 非负整数：db_schema、heartbeat/poll/event age、export_seq、min_retained_export_seq、pruned_max_export_seq。无 SQL、destination、credential 或异常文本。`db_state=OK` 必须满足 schema 4 及必需表/列，SQLite URI `mode=ro` + query_only + quick_check(1)。SQLite 工作有 .25 秒默认 deadline、最多 2000×1000 VM 指令、.1 秒锁等待；预算中断/忙为 UNKNOWN。文件不存在为 MISSING、OS 权限错误为 UNREADABLE、确定 schema 缺失为 SCHEMA_MISMATCH、SQLite 确定损坏为 CORRUPT，不把超时猜为损坏。

accountd 每轮先独立提交 heartbeat_at；last_success_at 仅成功 poll 提交时推进，失败 poll 回滚采集事务。heartbeat/poll 年龄共同判定 AUDIT_STALLED；last event age 不表示 loop 活性。使用诊断要求同 instance、年龄 -30～90 秒；诊断缺测、陈旧、回放或 DB UNKNOWN 不关闭已有审计 Finding。

| 诊断 / 推进状态 | 语义与影响 |
| --- | --- |
| COLD | 同 installation 首个可比较 export counter；不伪造 delta |
| ADVANCING / STATIONARY | 新且有序诊断的 counter 增长 / 不变；delta 数值可查。不变合法，因为 schema 4 仅连接关闭分配 export_seq |
| REGRESSED | 同 instance counter 低于高水位；新增 EXPORT_SEQUENCE_REGRESSION，Accounting UNKNOWN。保留高水位，追平后可确定恢复 |
| REPLAYED | observed_at 重复或倒退；不更新 counter baseline、不关闭已有 Finding，Accounting UNKNOWN |
| UNKNOWN | 缺 capability、传输/权限/时间/DB/数据证据不足；保留可用 baseline。新 instance 重建 baseline |

所有有序新鲜诊断（含 CORRUPT/UNKNOWN/REGRESSED）推进回放时间水位，防止旧健康响应关闭更新异常。Controller 内部保存 baseline/progression；公共 `health --json` / GET monitor 仍为严格 monitor/v1，不回显新增私有字段。Findings evaluations 的 `audit` 为白名单数值/布尔/固定状态，包含诊断时间、新鲜度、DB 状态、推进、heartbeat/poll/event age、retention watermark、received cursor 和 sync age；CLI/UI 默认读缓存。

诊断新增 SCHEMA_MISMATCH / ACCOUNTING_DB_CORRUPT 正反例；只有确定 DB OK 才闭合对应异常。EXPORT_GAP 可由同 instance 的 pruned watermark 超过已接收 export_seq 或持久 expired cursor 证明；不能用合法跳号/MIN(seq) 猜 gap。SYNC_LAG 优先使用独立诊断 counter，cursor 超前或诊断不可信时 UNKNOWN。

M1 新增 `finding_write_errors` 改变运行汇总形状，M2 将前台 `monitor --json` 明确版本化为 `monitor/v2`，保留已有 monitor/v1 health/cache/API 合同。新 v2 schema 和真实运行 JSON 校验已补；旧 v1 运行汇总消费者须按 schema 后缀升级解析。

## 存储与失败边界

M3 Node 增加 NETWORK_RATE_ANOMALY / SERVICE_RESTART_LOOP。统计基线和重启规则冻结于 [M3_NODE](../evidence/0.5.2/M3_NODE.md)；网络前置样本 ≥20、跨度 ≥540s、1h/60 样本，阈值 max(1MiB/s,4×median,median+6×MAD)。重启为连续观测 NRestarts 的 300s 差值累计 ≥3；boot/instance/counter reset/缺测为 UNKNOWN。M3用户新增独立[user-traffic/v1与三类检测](V0.5.2_User_Sampling_Design.md)，包含open connections，poll/provenance/retention边界及容量规则明确。私有detector_state与Finding/Timeline同事务保存；公开baselines仅固定原因与数值，user_coverage明确partial/缺测/容量。

- `findings.db` 与 `observation.db` 同一 machine-local 目录；M1/M2 schema1，M3用户schema2显式事务迁移增加user_evaluations，读取兼容1/2；不迁移或写Fleet/Node accounting DB。
- Finding / Timeline / Evaluation 同一 SQLite `BEGIN IMMEDIATE` 事务；读使用 `mode=ro` + `query_only`。写锁 timeout=2s；失败回滚并保留已有状态。
- resolved Finding 与Timeline保留90天；ACTIVE不因TTL自动关闭。M3用户后Finding≤32768（覆盖1024 Node×11 +4096 user×3并留历史余量）、Timeline≤10000、NodeEvaluation≤1024、UserEvaluation≤4096、DB≤128MiB；用户baseline按最后可用采样90天过期。满用户容量拒绝新准入并标CAPACITY，不每轮淘汰当前用户造成告警flood。
- 达到行数上限按最旧记录淘汰，包含 ACTIVE 的容量淘汰；`truncated` 明示历史不完整，淘汰后相同异常可重新打开。不得据此声称完整历史。
- 坏行隔离为 PARTIAL，坏 DB/未知 schema 为 CACHE_CORRUPT；不覆盖损坏的整库。坏旧行不能阻止其他有效记录写入。
- Monitor 先持久化 telemetry，再独立更新 Findings；后者失败单独计入 `finding_write_errors`，不丢弃已提交的 telemetry、不终止其他节点。`monitor` 返回非零并打印固定错误分类，不暴露异常内容。

## CLI / UI / Timeline

`findings [NODE] [--state ACTIVE|RESOLVED] [--limit 1..1000] [--json]` 默认仅读缓存。`--refresh` 显式重分析本地 observation cache 与 sync cursor，零 SSH，但会写 Findings cache。Monitor 自动更新同一缓存。

`timeline [NODE] [--limit 1..1000] [--json]` 与 GET `/api/findings`、`/api/timeline` 只读本地数据；GET 不运行 detector，不创建 lock/DB，不发起 SSH。UI 新增 Findings、Timeline 页面。

`timeline/v1` 映射 Finding open/resolve、health state change、已知 service active/inactive 变化、确定 probe result 变化及白名单 operation journal（含 sync/probe/verify）。M3 增加已知 NRestarts 增长的 SERVICE_RESTART 事件，detail 只含 restart_delta；不由回退/复位猜重启。时间戳倒序，再按稳定 event id 升序；坏 journal 行隔离；最多读取 8Mi 个字符 / 最后 5000 行，超限标 PARTIAL。单节点查询省略无节点关联的 Fleet/User operation；全局视图中的用户操作显示为 Fleet 事件，不回显原始 target。未知 operation 不回显。
