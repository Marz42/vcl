# Vincula 0.4.4 — Local Audit UI v2（D53-rev1）

**Stamp:** CTRL `0.4.4` · NODE `0.3.1`（不变）  
**Authority:** this file is the in-tree contract for D53-rev1 (six-page UI). Full roadmap: [`vcl-spec-v0.4-v0.5-rev1.md`](vcl-spec-v0.4-v0.5-rev1.md) §16.

## Goal

Bring the localhost Local Audit UI up to the 0.4.1–0.4.4 CLI surface **without** identity mutations.

| In | Out |
| --- | --- |
| Six pages: Overview / Nodes / Users / Traffic / Audit / Operations | UI identity mutations (add/rotate/retire/replace/restore/import) |
| UI Sync = `vcl-fleet sync --full` | Rendering VLESS URI / UUID / Reality private key / Clash secret |
| **Probe** = live SSH (`run_status_payload`); **Verify** writes `last-status.json` | Probe reloading cache-only Overview/Health (P1) |
| Recipes for adopt / provision / register / workspace / archive / `user link` | Running `node provision` from the UI |
| Read-only workspace strip (strict GET; five conflict states) | D57 observe≠admin, telemetry/v1 (→0.5+) |
| Local Operations history (sync / probe / verify / refresh-users) | |

## Non-negotiables (inherit AC-3.1)

1. **Loopback-only** bind (`127.0.0.1` / `::1`); refuse `0.0.0.0` / public.
2. **`identity_mutations: false`**; mutate POST routes remain **405**.
3. **`reseed` CLI-only**; UI POST `/api/sync` with `reseed` → **400**.
4. Default JSON / pages omit secrets (URI, UUID as credential, Reality private key, Clash secret).
5. Closing the UI process does not affect VPS nodes.
6. **Probe must not write** `last-status.json`; live results render in UI overlay until Sync/Verify reloads cache.

| ID | Criterion |

| **AC-4.4-05** | Overview/Nodes expose read-only `fleet_id` + workspace conflict (`ok` / `WORKSPACE_*` / `absent`); GET never mkdir / never migrate workspace-view / never `remember_workspace_view` |
| **AC-4.4-06** | Recipes / meta JSON contain no VLESS URI and no secret material |
| **AC-4.4-07** | Existing AC-3.1-01..11 fixtures remain green |
| **AC-4.4-08** | **Probe** POST `/api/refresh/probe` returns live `result`; GET `/api/nodes` stays cache; UI renders live overlay without rewriting cache |
