## M1：冻结的 Node Inspect 合同

固定命令 `vcl inspect --json`，capability 为 `inspect/v1`，observer 只接受这两个参数。安装、runtime-only、升级 checkpoint/rollback、卸载与 Node/Controller 制品清单均包含 collector。M1历史证据保持不变；当前Controller已接入cache-only Inspect、显式baseline、Drift和增强Verify。

[正式 schema](../../schemas/inspect/v1.schema.json)与 `lib/inspect_snapshot.py` 的 `contract()` 必须相等，正反 fixture 同时经过正式 schema 和完整 runtime validator。所有字段固定、禁止附加字段；root 含 schema、node_id、instance_id、observed_at、state。root OK 必须身份完整且全部分项 OK；身份未知为 UNKNOWN，其余不完整为 PARTIAL。node_id 与 instance_id 不相同。

每分项固定 `state=OK/PARTIAL/UNKNOWN/UNSUPPORTED/UNREADABLE`、`reason=NONE/MISSING/MISSING_TOOL/PERMISSION/INVALID/LIMIT/TIMEOUT/COMMAND_FAILED/SYMLINK/UNSUPPORTED_OS`。OK 必须 reason NONE；不可读、缺工具、超时和不完整不变成健康零。数组截断必须 PARTIAL/truncated=true。

| 分项 | 冻结字段与含义 |
| --- | --- |
| OS / CPU / memory | ID、VERSION_ID、kernel、supported；CPU 数；RAM 与 swap total/available 字节。支持矩阵 Debian 12/13、Ubuntu 22.04/24.04/26.04；其他 OS 明确 UNSUPPORTED。available 大于 total 拒绝 |
| filesystems | 固定 `/`、`/var`、`/run`、`/tmp` 的 capacity/available 字节与 filesystem；只代表这四个路径，未知 mount type 为 PARTIAL |

| interfaces / qdisc | 网卡 name/MTU/admin-up/loopback；qdisc interface/kind/root。接口枚举最多读取65项、保留64项；不宣称包含全部网卡 |
| selected sysctl | TCP congestion control、default_qdisc、IPv4/IPv6 forwarding、tcp_mtu_probing、somaxconn；固定 proc 文件，无写入 |
| limits / services | system file-max、当前 observer 进程 nofile soft/hard（不是 sing-box limits）；sing-box/accountd 固定 unit 的 active/enabled/restart count/User/Group/nofile soft/hard |
| versions | CLI VCL、installed VERSION；sing-box 版本仅在安装 lock 记录的 binary SHA 与实际字节一致时为 INSTALLED_MANIFEST，否则 UNKNOWN；禁止执行受检 binary |
| listeners | TCP/UDP、IPV4/IPV6/ANY、LOOPBACK/LINK_LOCAL/NON_LOOPBACK、规范地址、zone interface、port。固定 ss 无 process/argv；非 loopback 并不等于公网实际可达 |

## 只读、秘密与资源边界

collector 默认共享6秒预算，内部最多8秒；每个固定外部 argv 最多1秒、stdout≤64KiB、stderr丢弃。Linux 使用有界 pipe drain，超时/超量 kill 整个 process group，包括父进程先退出的子进程；无 shell。固定 sys/proc/小文件≤1MiB，config≤4MiB，binary streaming hash≤256MiB；输出 compact JSON≤64KiB；公开数组≤64项。非 regular 文件拒绝，配置/lock/指纹文件拒绝 symlink，检查读取期间及路径标识变化。无需执行受检 binary、package refresh/update、restart、sysctl 写入或 reconcile。

observer unit允许AF_NETLINK供只读ss/tc读取，CapabilityBoundingSet仍仅CAP_DAC_READ_SEARCH，不增加CAP_NET_ADMIN。防火墙工具可能因权限受限失败，保留UNKNOWN/COMMAND_FAILED；没有现场证明完整firewall覆盖。systemd隔离与实际工具权限在PENDING LIVE中核对。

config 仅识别当前受管 renderer 的严格字段集合，拒绝 duplicate key、non-finite、未知 shape/字段、非法类型。VLESS credential UUID、Reality private/short keys、Clash secret 在 canonical hash 前删除；secret rotation 不改变 non-secret fingerprint。用户/tag、listener、route/outbound 顺序等有效非秘密行为改变会改变 hash。响应含逻辑 node/instance UUID，不含用户 credential UUID。模式或权限未知不冒充安全。

Controller fetch 固定 `vcl inspect --json` 后读取 `vcl identity --json`，校验 registry node_id 与当前 instance_id；仅 observe 凭据，无 admin fallback，capability 缺失不 SSH。调用方必须提供一次覆盖 capability/inspect/identity 的总 deadline。M2已接入monitor，capability/telemetry/audit/users/inspect/identity共用Node总deadline；默认15秒，Inspect低频默认300秒（60～600秒）。缺测不丢弃有效telemetry，独立写失败计数见monitor/v3。

property 依据：[systemctl show](https://github.com/systemd/systemd/blob/main/man/systemctl.xml)、[timedate1 property](https://github.com/systemd/systemd/blob/main/man/org.freedesktop.timedate1.xml)、[service exec limits](https://github.com/systemd/systemd/blob/main/man/systemd.exec.xml)。读取单位含义以分项定义为准，原始工具输出不会回传。

## M2：Controller cache / baseline / Drift

实现合同见[冻结设计](V0.5.3_Baseline_Design.md)，证据见[M2](../evidence/0.5.3/M2_CONTROLLER.md)。`vcl-fleet inspect [NODE] --json`、`GET /api/inspect`和UI均仅读缓存；指定Node的CLI/API含完整脱敏snapshot，Fleet列表只含摘要。独立inspection.db使用只读连接、query_only、事务、.1秒锁等待、1秒/200万VM步预算及128MiB上限。latest/baseline各1024，latest7天，baseline显式保留；容量拒绝新目标，不淘汰接受的baseline。

`baseline accept NODE --sha256 SNAPSHOT_SHA`显式选择LOCAL_ACCEPTED参照；事务重新检查snapshot SHA、endpoint、当前instance、新鲜性与完整必要覆盖。当前telemetry身份读事务保持至CAS提交，阻止换机身份更新在提交中途穿过。`baseline clear NODE --sha256 BASELINE_SHA`显式CAS删除。首次观察、monitor和GET不接受基线。基线与baseline Timeline事件同一数据库事务；LOCAL_ACCEPTED不代表实机或Human Gate。

比较listeners、services（不含restart count）、versions、config、units、runtime、binary七分项，MATCH/DRIFT/UNKNOWN；任一DRIFT优先，未知不误恢复。无baseline、陈旧、重放、时钟偏差、换instance、endpoint改动、缺权限/缺项/截断为UNKNOWN。七类DRIFT_*复用稳定Finding id/恢复/重开；Findings公开合同升findings/v2，Timeline升timeline/v2。旧v1冻结，私有Findings schema2无需破坏迁移；容量拒绝入场并保留已有ACTIVE。

## M3：增强 Verify 与兼容

固定Node命令`vcl verify --extended --json`及capability `verify/v2`；observer exact argv，不接受任意路径。旧`vcl verify --json`的identity/proxy/accounting/utc_now与退出语义保持，升级/恢复仍使用旧合同。Master起草时希望增强同一argv；现有接口已被严格旧合同与consumer冻结，因此本版本选择独立--extended入口及v2后缀，避免隐式破坏既有升级/恢复。

| 分项 | PASS依据与限制 |
| --- | --- |
| Identity | settings逻辑node与安装态state.node的node/instance一致且不同；Controller另核对RPC后当前identity |
| Configuration | 与settings/state/users生成的canonical accounting配置完整相等，包括内部秘密一致性；只输出结果，不返回值；这是受管形状/一致性检查，不运行受检binary做语法测试 |
| Integrity | 实际sing-box SHA与安装sing-box.lock一致；这是本机安装record比较，不能证明record没有被管理员改写，也不等于整套runtime供应链验签 |
| Permissions | Linuxsettings/state/users/sing-box配置regular/root-owned、无group-write/world权限，group-read限root或配置所需sing-box组；16项可见artifact无group/world-write；缺测UNKNOWN；非Linux UNSUPPORTED |
| Services | 两个受管service active/enabled，使用固定sing-box/vincula-accountd user/group；不代表systemd全部隔离条件通过 |
| Listeners | 实际配置VLESS bind/port与Clash loopback端口存在，Clash配置或同端口TCP非loopback暴露FAIL；不假定Clash固定9090，不证明进程所有权/公网可达 |
| Accounting | 有界只读schema4结构/quick_check、heartbeat和成功poll≤90秒；inactive/stale/已知损坏FAIL，锁/失测UNKNOWN；不证明业务流量准确或计费级质量 |
| Data Plane | Node始终UNKNOWN/NO_PROBE；Controller只在显式专用probe成功且probe后identity仍一致时PASS；真实探测失败FAIL，缺配置/runtime/身份变更UNKNOWN |

总结果任一FAIL为FAIL，否则存在UNKNOWN/UNSUPPORTED为UNKNOWN，全部PASS才PASS。Node共享8秒collector/文件/SQLite预算，固定argv≤1秒；不执行受检binary、update/restart/reconcile。Controller`verify --extended --name NODE --json [--probe-profiles PRIVATE_FILE]`共用默认15秒Node deadline，RPC及probe后identity都用observe，认证失败不fallback；私有probe文件沿用现有专用用户/固定版本验证。公开合同为verify/v2、fleet-verify/v2；实际Live代理对照仍待验收。
