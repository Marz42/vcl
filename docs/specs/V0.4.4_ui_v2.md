# Vincula 0.4.4 — Local Audit UI v2（D53）

**Stamp:** CTRL `0.4.4` · NODE `0.3.1`（不变）  
**Authority:** this file is the in-tree contract for D53. Prior 0.4.x “rev1 spec” sections for UI v2 were not checked in; 0.4.1 evidence deferred **UI Sync→`--full`** and **UI v2 / D53** to later milestones — this release closes them.

## Goal

Bring the localhost Local Audit UI up to the 0.4.1–0.4.3 CLI surface **without** identity mutations.

| In | Out |
| --- | --- |
| UI Sync = `vcl-fleet sync --full` | UI identity mutations (add/rotate/retire/replace/restore/import) |
| Recipes for adopt / provision / register / workspace / archive / `user link` | Rendering VLESS URI / UUID / Reality private key / Clash secret |
| Read-only workspace conflict / `fleet_id` on Overview & Health | Running `node provision` from the UI |
| Keep three pages (Overview / Audit / Health) | D57 observe≠admin, telemetry/v1, node-add deprecation warnings (→0.5+) |

## Non-negotiables (inherit AC-3.1)

1. **Loopback-only** bind (`127.0.0.1` / `::1`); refuse `0.0.0.0` / public.
2. **`identity_mutations: false`**; mutate POST routes remain **405**.
3. **`reseed` CLI-only**; UI POST `/api/sync` with `reseed` → **400**.
4. Default JSON / pages omit secrets (URI, UUID as credential, Reality private key, Clash secret).
5. Closing the UI process does not affect VPS nodes.

## D53 acceptance criteria

| ID | Criterion |
| --- | --- |
| **AC-4.4-01** | POST `/api/sync` invokes `run_sync_full_payload` (identity+health+users+audit → cache), not legacy `run_sync_payload` |
| **AC-4.4-02** | Sync PARTIAL / non-zero exit is surfaced (`ok=false` / toast); UI never pretends SUCCESS |
| **AC-4.4-03** | `/api/recipes` includes adopt, provision, register, workspace init/verify/export/import, audit archive create/restore, `user link TAG --node NAME`; `node add` retained as **legacy alias** |
| **AC-4.4-04** | Empty Health/Overview copy points at adopt/provision (not only “node add”) |
| **AC-4.4-05** | Overview/Health expose read-only `fleet_id` + workspace conflict code (`ok` / `WORKSPACE_ROLLBACK` / `WORKSPACE_DIVERGED` / `WORKSPACE_INCONSISTENT` / `absent`); no SSH to fill gaps |
| **AC-4.4-06** | Recipes / meta JSON contain no VLESS URI and no secret material |
| **AC-4.4-07** | Existing AC-3.1-01..11 fixtures remain green |
