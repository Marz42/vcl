# 0.5.2 用户采样合同

状态：**IMPLEMENTED / M3 PASS OFFLINE / 未发布**，2026-10-04。独立 user-traffic/v1、三类用户 detector、缓存与CLI/UI已实现；当前候选stamp0.5.2。用户范围证据见 [M3_USER](../evidence/0.5.2/M3_USER.md)，最终合同/制品见 [M4](../evidence/0.5.2/M4.md)。

已核对 schema 4：export_seq 仅 closed connection 分配；daily_usage 是按 closed_at（未关闭用 started_at）聚合的重建视图，不能当实时计量。当前实现从同一只读 accounting SQLite 事务内读取 last_success_at、heartbeat_at、retention pruned watermark 和每 logical user 的全部 retained connection bytes（含 open）及当前 open count；不将 Node 总量或仅 export closed 的批次充作用户数据。

独立 `user-traffic/v1`，固定 `vcl telemetry users --json` observe 命令、capability 协商与共享单节点 deadline，不改 telemetry/v1 或 audit-health/v1。响应限制最多64个用户/32KiB，按稳定 logical identity 选取；超限/坏行明确 PARTIAL，缺失用户 UNKNOWN。user key 为 lowercase logical user_id 的SHA-256，展示 tag 只接受既有32字符白名单，缺tag用固定hash前缀标签；不回传 destination、connection id、credential UUID、URI 或错误原文。Node DB 工作保持 .25s/2000×1000 VM step/.1s锁预算；格式/损坏/权限不合并成正常空列表。aggregate overflow 为UNKNOWN，确定损坏为CORRUPT；不从异常自由文本猜测。

响应同时提供查询 observed_at 和成功 poll sampled_at。仅相同 instance、成功 poll 时间严格前进、采样间隔 ≤90s、counter 不回退且 retention watermark 未变化的 retained-byte 差值可计算 rate；poll 冻结/回放、retention/DB restore/reset 都重建 baseline 并显示 UNKNOWN。累计值属于 retained window，明确 approximate，不冒充 lifetime/billing-grade counter。事务快照使 poll 时间和 rows 一致；aggregate overflow、partial row、budget interrupt 不输出伪零。

用户流量/连接分别复用 M3 rolling median/MAD：20个前置正常样本、≥540s跨度、1h/60样本；绝对 floor 为流量1MiB/s、连接20，阈值 max(floor,4×median,median+6×MAD)，ACTIVE恢复 <85%。SUSTAINED_TRAFFIC_ANOMALY 要求异常连续300s，任何证据缺口中断待触发持续窗口、UNKNOWN不关闭已触发事件；对完全相同缓存的显式refresh不制造采样缺口。长时异常不会训练自身，基线过期为UNKNOWN保留ACTIVE。固定合成正常/异常、冷启动/缺测/retention/重装及脱敏测试冻结上述阈值；现场误报验收仍PENDING LIVE。

每 node/user 独立 subject：节点hash、用户hash与组合稳定key，kind=user，显示node/tag；过滤/节点改名保留key，用户tag变化不换去重键。Findings本地schema 1→2显式事务迁移增加user_evaluations与parent索引；读取仍兼容schema1，默认GET不迁移。node evaluation≤1024、user evaluation≤4096、Finding≤32768、Timeline≤10000、DB≤128MiB。活动与缺测用户不因每轮新用户到来而反复淘汰/重开：用户容量满拒绝新baseline admission，标truncated/user_coverage=CAPACITY及skipped数量；未准入不产生伪NORMAL。用户baseline距最后可用采样90天过期，ACTIVE Finding不据此自动关闭。UI/CLI默认公开固定原因及数值摘要，不暴露原始baseline；公开user evaluations受limit≤1000，node evaluations受1024上限。

monitor内部保存用户样本，公共monitor/v1形状不增加字段；用户source/missing/partial/capacity信息从Findings evaluations.user_coverage显示。user状态与node状态/Finding/Timeline在同一事务提交，故障整体回滚。schema/Fixture和打包成员已补；全量验证绑定各自SOURCE_INPUTS，不复用旧候选。
